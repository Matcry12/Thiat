# 0021 — Procedural grass arena from a third-party tile pack

## Context

The user wants the test room to look like a combat area, and wants maps generated by algorithm so
replays stay fresh. Drawing our own art is slow; a free pack lets us see the look now.

## Decision

- Art: **Pixel Crawler — Free Pack** (Anokolisa), kept untouched in `assets/third_party/pixel_crawler/`.
  Commercial use allowed, no credit required, art may not be resold (`Terms.txt`). The 3 sheets we
  use are copied to `assets/map/` (Godot needs to write `.import` files next to them).
- **Pixel scale 2x** (16 px tile → 32 px), the same grid as the swing FX `pixel_size`.
- Characters will be **head + body, no hands** — the weapon floats beside the body (Soul Knight).
  Not in this pack; placeholder bodies stay for now.
- Generator split into data / logic / nodes: `MapStyle` + `PropSet` resources (`data/maps/grass.tres`),
  pure `MapGen` (seeded, testable headless), `ArenaMap` node that builds layers from the result.
  New art = new `.tres`, no code change.
- The grass edge set has no concave or 1-wide pieces, so **dirt patches are rectangles ≥2x2, at
  least 2 cells apart**; wavy edges + deco hide the shape.
- **Rocks only outside the FightZone**: the boss has no pathfinding. Rocks do not block the boss
  body (otherwise the player could hide from the enraged boss); they block the player and projectiles.
- `map_seed = 0` → new map every run, including R/Restart. A typed seed reproduces a map exactly.

## Why

Same rules as the rest of the game: art is a swap, numbers live in `@export` (F3 + `New map`),
gameplay must not depend on the look.

## Consequences

- Rocks inside the fight zone need boss pathfinding first.
- L-shaped / organic patches need 4 hand-drawn concave corner tiles.
- Ground type has no gameplay effect yet (mud, water = later).
