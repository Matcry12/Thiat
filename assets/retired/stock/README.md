# assets/retired/stock — third-party art, NOT cleared for release

`sword_diagonal.png` came from a Dreamstime stock image
(`pixel-video-game-sword-icon-cartoon-retro-style-set-108038150`), background removed and
downscaled to the true pixel grid.

**This is not licensed for distribution.** It is fine for private testing, but it must be
replaced before the game is shared, published or sold. Safe replacements: Kenney.nl (CC0),
itch.io asset packs with a clear licence, or original art.

Swapping it is the 3 steps in `docs/wiki/replacing-art.md` — no code change.

`sword_straight.png` — from a pngtree stock image (`images.png`), background flood-filled to
transparent and downscaled to its true 15x48 pixel grid. Points UP in the file, so
`art_angle_degrees = -90`. Same licence warning as above: testing only, replace before release.
